# Tools

This directory contains the implementations of tools available to agents.

## Files

- `mathy.go`: Provides simple mathematical tools (`sum`, `sub`) as examples of function-based tools.

## Subdirectories

- `browser/`: Browser automation tool using Playwright.
- `cache/`: Tools for managing agent state/cache.
- `exec/`: Tool for executing shell commands in the environment.
- `filesys/`: Tools for filesystem manipulation (`read`, `write`, `edit`, `list`, etc.).
- `mcp/`: Integrations for Model Context Protocol (MCP) tools (GitHub, Tavily).
- `meta/`: Tools for meta-operations (empty/placeholder).
