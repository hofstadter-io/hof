# MCP Tools

This directory contains Model Context Protocol (MCP) tool integrations.

## Files

- `github.go`: Configures the GitHub MCP toolset using the `github.com/modelcontextprotocol/go-sdk`.
- `local.go`: Implements a sample in-memory MCP server with a `get_weather` tool.
- `tavily.go`: Configures the Tavily search MCP toolset.
