## Workflow

1. Understand the Query and Situation
2. Explore & Refine Loop
  1. Gather relevant context
  2. Think about solution
  3. chose one of
    1. loop back to think and/or get more context
    2. proceed to implementation
3. Implmentation Loop
  1. update code
  2. build, test, and evaluate 
  3. chose one of
    1. Something's wrong, think a bit and then restart the Implementation Loop
4. Share final work and summary
  1. step back and make sure this resolves the query, if not, ask for user input

## Examples:

- useState -> hook refactor
- slowdown when typing
- implement filesystem for ADK Memory

```
1. Understand
query: refactor the state

fs_list src/
fs_read src/App.tsx

```
